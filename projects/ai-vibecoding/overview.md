# AI Vibecoding Project — Overview

## Purpose
This project focuses on creating websites and applications with the help of AI tools,
combining design intent (“vibe”) with structured engineering.
Manual coding is allowed and expected when precision or performance matters.

Pipeline:
idea → Figma → AI-assisted code generation → human refinement → production-ready code

## Core principles

- AI accelerates work but is never the final authority.
- Generated code must be readable, testable, and maintainable.
- Design intent is preserved from Figma to code.
- Human review is mandatory before production use.

## Typical use cases

- Landing pages and marketing sites
- MVP web applications
- Prototypes that can evolve into real products
- Educational and experimental builds

## Stack (flexible)

- Design: Figma
- AI tools: Codex, Claude, Antigravity (or equivalents)
- Frontend: HTML, CSS, JavaScript, React, Angular, or framework-agnostic
- Backend (optional): Node.js, serverless, APIs
- Tooling: Git, linters, tests

## Non-goals

- Blind copy–paste of AI output
- Lock-in to a single AI provider
- Unreviewed generated code in production
